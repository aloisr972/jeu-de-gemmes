Comment placer

Cliquez une gemme dans le bac, puis cliquez sur le plateau pour la poser. Faites glisser une gemme posee pour la deplacer. R pivote, Suppr retire.

Les gemmes forment un tangram de 4x4 cases. Le grand triangle et le petit triangle ne se posent que l'hypotenuse alignee sur la grille ; le carre se pose toujours en losange. C'est la regle b du livret.

Reponses de l'adversaire

Recopiez ici ce que l'adversaire vous annonce dans le chat. Rien n'est verifie ni calcule : la ligne est ajoutee telle quelle. Pour une question sur une case, tapez la coordonnee a gauche (C6) et laissez la sortie vide.
Une reponse transparente / rien barre automatiquement de croix ce qu'elle prouve vide : toute la ligne entre deux reperes qui se font face (A et 11, 3 et K...), ou la seule case interrogee. Une reponse coloree ne declenche rien.
